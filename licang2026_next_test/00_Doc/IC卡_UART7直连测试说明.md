# IC卡 UART7 直连测试说明

## 1. 测试目的

本测试不经过四路串口复用模块，使用 F7 的 UART7 直接连接 M2940B-HA
读卡器，先验证读卡器参数、A3 读块命令、DMA 空闲接收和比赛球数据解析。

电脑通过 USART1 发送“球已放好”命令，F7 才发起一次读卡。这个时序与后续
“放球完成 -> 读球 -> 保存行列 -> 转盘移走”的比赛流程一致。

当前只完成代码与编译验证，尚未完成实机闭环。

## 2. 接线

| F7/模块 | 连接对象 | 说明 |
| --- | --- | --- |
| UART7 TX | 读卡器 RX | 3.3 V TTL，收发交叉连接 |
| UART7 RX | 读卡器 TX | 3.3 V TTL，收发交叉连接 |
| PB1 / `IC_CARD_IO` | 读卡器 IO | 可连接用于后续观察有卡提示；本次读值逻辑不依赖该电平 |
| F7 GND | 读卡器 GND | 必须共地 |
| USART1 PA9 | CH340 RX | 调试文本输出 |
| USART1 PA10 | CH340 TX | 接收电脑命令 |
| F7 GND | CH340 GND | 必须共地 |

读卡器供电电压应按实物接口标注和厂家资料连接，不要仅凭 TTL 电平推断电源脚电压。

## 3. 推荐参数

以下是当前比赛用法的工程建议，不等同于“设备出厂默认值”：

- 设备地址：`0x20`；与当前已验证设备一致时无需反复写入。
- 串口：`115200, 8-N-1`；该波特率与当前 F7 UART7 和此前上位机实测一致。
- 工作模式：命令模式。球放稳后由 F7 主动发送一次 A3，避免自动上传产生重复球数据。
- 读取块：扇区 0 的块 1，即绝对块号 `1`。
- 操作提示参数：以厂家《高频读写器使用手册V1.0.5》和STM32示例代码为准，
  `1`表示开启本次操作的蜂鸣/灯提示，块1读取帧为
  `01 08 A3 20 01 01 00 75`。参数为`0`时帧才是`01 08 A3 20 01 00 00 74`。
- 自动读卡：命令模式下不参与本流程；无需为了本测试反复写 EEPROM。
- 蜂鸣器总开关：可以开启用于调试，但不能把蜂鸣声当作“球值已解析有效”。
- 韦根输出：本项目使用 UART 协议，建议关闭或不接。
- Key A：必须与比赛 IC 球实际密钥一致。未用正式样球验证前，不得假定一定是
  `FFFFFFFFFFFF`；A3 使用的是读卡器内部保存的 Key A。

厂家协议要求连续命令留出至少 100 ms；参数写入 EEPROM 后不要高频重复设置。
测试代码上电后额外等待 5.2 s 再接受读卡触发，以避开资料所述参数设置保护时段。

## 4. 测试开关

唯一开关在 `05_Test/test_config.h`：

```c
/* 裸机直连测试 */
#define LICANG_ACTIVE_TEST LICANG_TEST_IC_CARD_BAREMETAL

/* 或 FreeRTOS 完整分层测试 */
#define LICANG_ACTIVE_TEST LICANG_TEST_IC_CARD_FREERTOS
```

两种模式不能同时开启，也不能与 UART7 复用测试同时开启。代码交付时默认保持：

```c
#define LICANG_ACTIVE_TEST LICANG_TEST_NONE
```

## 5. 串口助手操作

USART1 串口助手设置为 `115200, 8-N-1`，以 ASCII/文本方式发送：

```text
BALL_READY
```

也可以发送短别名：

```text
READ
```

允许串口助手自动追加 CR/LF。正常过程会依次看到：

```text
IC CARD ... TEST READY. PLACE BALL THEN SEND BALL_READY
BALL READ START
BALL OK CODE=0x23 ROW=2 COL=3 DATA=23 23 ... 23
```

常见失败文本：

- `BALL ERROR TIMEOUT`：没有收到完整响应，检查接线、波特率和 UART7 DMA/IRQ。
- `BALL ERROR NO_CARD_OR_KEY`：厂家状态码表示读卡失败，可能无卡、距离不合适或 Key A 不匹配。
- `BALL ERROR INVALID_BALL_DATA`：读块成功，但 16 字节不一致或不是当前规则的 1~3 行、1~4 列编码。
- `BALL READ BUSY`：上一笔读卡尚未结束，不会叠加第二笔事务。

## 6. 当前规则解析

2026 初步规则中，比赛球数据位于扇区 0 的块 1，16 个字节应为同一个值。
高半字节表示行 `1~3`，低半字节表示列 `1~4`。例如 `0x23` 表示第 2 行
第 3 列。2026 初步规则已取消干扰球，所以 `0x14` 在本代码中表示第 1 行
第 4 列；不要继续沿用 2025 对该值的旧解释。

## 7. 后续接入复用模块

本轮 UART7 直连只验证 IC 协议和真实硬件。直连通过后，再新增复用事务适配，
由串口复用 Service 管理读卡器所在通道。协议构帧、校验、球值解析和上层语义
接口应继续复用，不能在复用测试中重新写一套读卡协议。
