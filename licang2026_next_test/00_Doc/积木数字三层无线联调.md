## 已确认流程与边界

裁判补充规则：第4列初始为空，每行至多一个积木。数字1/2/3表示第4列的目标层，不等于当前扫描层。三阶段均在识别到后跳过本层剩余点位去D4；允许某行没有积木。

模型继续使用已有best.engine和preview_env，不重训、不重建或重装PyTorch/CUDA。MF500负责积木和球，C100继续负责仓库底部数字。正式响应器共用摄像头，禁止并行运行独立预览抢占设备。

## 起点握手和识别有效时间

- Nano程序启动即在专属线程异步加载及预热模型，只做一次；此时不持续推理。
- F7起点每1秒查询模型；只有动作10实际完成、底盘就绪及模型READY才发出起点就绪握手。模型加载十几秒不算识别启动超时；加载失败故障停车。
- 每层先确认动作10完成，再执行28/29/30并等待匹配的完成回报。10完成缓存有效则跳过重复10；同层横移不重复机械臂动作。
- 停车与动作完成后等200ms，再开启该停点的新SID；Nano在READY处清空旧帧及计数，仅接受此后的新采样帧。动作运行中的底层/其他层数字不能作为该停点结果。
- 数字门槛0.80、连续3张新帧唯一候选一致即确认；首张有效新帧起1500ms且累计至少15帧仍无确认，返回NO_VALID并保留原因。
- 无候选/低分/冲突/跳变均按无有效数字跳站；设备、缺帧、模型或通信错误故障停车。NO_VALID不证明物理空仓。
- START相机准备保护10秒，收到匹配READY后4秒为通信保护；业务判定由Nano管理。旧C100仓库识别仍从READY开始计时，不套用积木启动期限。
- Nano锁存一轮结果直到ACK或STOP，F7等ACK写完成才移动。旧SID、过旧结果或运动状态不能确认。

## F7无线测试

烧录最新无线固件（MISSION_CHASSIS_ROUTE_TEST_ENABLED=1），复位F7和底盘。先启动上述Nano程序，再通过USART1无线串口115200/8N1发送指令，每条以换行结束：

```text
RED
```

或仅发BLUE选择蓝方，等待：

```text
READY ARM=10 MODEL=READY PLATFORM STAIR DISC DEPOT OR ROUTE
```

STATUS可查看ARM_READY和MODEL_READY；之后发送新的测试命令：

```text
ROUTE BLOCK DIGIT
```

完整测试顺序：

1. 沿既有纯路径经过圆盘、阶梯、小圆盘到仓库D1，不夹球、不放球，不旋转车载转盘。
2. D1确认10→28完成，高层从D1到D2、D3依次识别。识别到数字立即回报、停1秒、去D4，跳过剩余点位。
3. D4确认10→29完成，中层倒走D3、D2、D1。识别到即回报、停1秒、去D4。
4. D4确认10→30完成，底层倒走D3、D2、D1。识别到即回报、停1秒、去D4。
5. 一层三个点均NO_VALID，回报NOT_FOUND并去D4换层。三层结束D4执行10完成后回家，收到HOME_READY才结束。

典型F7回报：

```text
BLOCK ROW=3 D2 DIGIT=2 TARGET_ROW=2 RESULT=DIGIT REASON=CONFIRMED FRAMES=3 ELAPSED=192ms SID=7
DONE BLOCK DIGIT HOME FOUND_ROWS_MASK=0x07
```

ROW是扫描层，TARGET_ROW是数字指定的目标层。FOUND_ROWS_MASK的bit0/1/2对应扫描层1/2/3；0x07代表三层均发现数字，空行导致掩码较小属于允许结果。此处打印数字代替抓取，D4不执行放置动作。

任何阶段可发STOP。STOP和故障后不自动恢复，保留日志并复位重新开始。一次路线结束后再测另一方也先复位F7和底盘。

## 首次联调验收

重点核对动作28/29/30均只在每层执行一次，每次前先回10；同层横移不重复动作。初始姿态和动作运动过程没有BLOCK RESULT，停车与动作完成后才出现BLOCK SESSION READY。

遇到过旧帧，日志新增BLOCK FRAME：read_age_ms是交付给处理线程时的帧年龄，age_ms包含模型排队和处理；infer_ms是TensorRT推理耗时，process_ms是预处理、推理和解析总耗时。generation标识算法会话代次，用邻近BLOCK SESSION READY的SID关联；日志仅打印首帧、过旧帧和故障，不打印所有正常帧。

分别把目标放D1/D2/D3、测试空行及三层不同数字，核对识别到后剩余点位跳过、停1秒、D4换层和最终回家。异常记录F7的ROW/D/SID/REASON及Nano同SID日志；低分螺丝钉应为NO_VALID，不能直接抓取。
