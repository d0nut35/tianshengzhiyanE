# 小圆盘纯路径无线调试

需要MISSION_CHASSIS_ROUTE_TEST_ENABLED=1并重新构建、烧录。选色RED或BLUE、底盘握手完成后使用。

1. 发送 `DISC_READY`：从当前未完成阶段沿既有路线前进，跳过前段视觉抓取，到小圆盘绕行起点实际停车，输出 `DONE DISC_READY` 和 `READY DISC_RUN`。前段已完成时不重复执行。
2. 在停车位置手动将机械臂摆至所需姿态，开启Nano小圆盘预览或积木采集工具。这条命令不启动视觉或下发机械臂动作；启动时已有的动作10行为不变。
3. 发送 `DISC_RUN`：直接下发既有SMALL_DISC_START，执行完整绕行及原有退出平移，结束后停车并输出 `DONE DISC_RUN` 和 `READY DEPOT`。不会重走前段路线。
4. 需要去仓库时发送 `DEPOT`：到D1后停住，不识别、不放球。

停在起点时可发STATUS、BALLS、HELP或STOP；其他路线命令须先完成DISC_RUN。STOP沿用已有停车机制，停止后需复位重新开始。命令运行中其他非查询/STOP指令回复BUSY，因此应等待DONE后再发送下一条。

原 `DISC` 仍是一条命令完成到位、绕行及退出；`ROUTE DISC` 仍是视觉抓取测试。DISC_READY/DISC_RUN只用于纯路径，支持手动调整机械臂及独立视觉观察。起点等待无时间限制；通信、路线失败或绕行超时沿用FAULT处理。

主机回归已覆盖两步顺序、重复命令、跨阶段、失败和STOP分支；不代表实机位置、绕行姿态或安全间隙已经验证。
