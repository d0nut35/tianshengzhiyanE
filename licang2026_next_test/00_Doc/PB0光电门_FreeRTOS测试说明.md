# PB0光电门FreeRTOS测试说明

## 1. 测试目的

本测试读取PB0数字电平，用于确认转盘螺丝是否对准光电门。真实F7已经重复测得：
螺丝未对准时PB0=0，对准时PB0=1。原始`GATE`命令仍只显示一次采样；自动逐槽
命令会结合ZDT到位状态，并要求PB0连续3次为1。

当前与UART7复用模块FreeRTOS集成测试共用USART1调试口，电脑发送`GATE`即可
读取PB0，不需要切换UART7通道。

## 2. 当前工程配置

- 光电门OUT：PB0。
- CubeMX模式：GPIO Input。
- 内部上下拉：Pull-up。
- 调试口：USART1，PA9 TX、PA10 RX，115200、8N1。
- 活动场景：`LICANG_TEST_MULT_UART_MODULES_FREERTOS`。

PB0当前已经由CubeMX生成代码配置为上拉输入，本轮不修改`.ioc`。

## 3. 接线和电平安全

```text
光电门 OUT -> F7 PB0
光电门 GND -> F7 GND
光电门 VCC -> 按模块铭牌/资料供电
```

F7 GPIO不能直接承受5V推挽高电平。若光电门使用5V供电，连接OUT到PB0之前，
必须用万用表或示波器确认OUT最高电压不超过3.3V，或者确认它是开集电极/开漏
输出并由PB0侧上拉到3.3V。不能因为模块VCC允许5V就假定OUT一定是3.3V。

## 4. USART1命令

发送：

```text
GATE
```

返回只有两种：

```text
GATE PB0=0
```

或：

```text
GATE PB0=1
```

这里是一次PB0原始采样；当前实机标定中1表示螺丝对准、0表示未对准。

## 5. 实验步骤

1. 先不要运动转盘，确认接线、共地和OUT电压安全。
2. 让螺丝明显离开光电门检测位置，连续发送3次`GATE`，记录背景电平。
3. 手动缓慢转动转盘，让螺丝进入检测位置，连续发送3次`GATE`，记录到位电平。
4. 让螺丝移出检测位置，再发送3次`GATE`，确认电平能恢复。
5. 只有当“离开值”和“到位值”稳定相反，才记录光电门有效极性。
6. 上电初始螺丝对准且`GATE PB0=1`时，先发送`ZDT_OPTIONS`确认Emm闭环配置。
7. 发送`ZDT_COARSE_CW`：位置模式粗走电机140.0度；等待`ZDT_STATUS`返回
   `REACHED=1`后读取`GATE`。它可能直接为1，也可能停在下一螺丝前而为0。
8. 重复发送`ZDT_FINE_CW`：每次位置模式走电机1.0度、15 RPM；每一步都等
   `REACHED=1`后读取`GATE`。第一次稳定读到PB0=1即到达下一螺丝。
9. 微调最多执行10次；仍未得到PB0=1则停止测试并检查角度、接线和机构，不能
   无限继续转动。
10. 反方向使用`ZDT_COARSE_CCW`和`ZDT_FINE_CCW`，搜索过程中始终保持同一方向，
    避免传动反向间隙影响结果。
11. 手动标定完成后，可在起点PB0=1且本次复位已成功发送`ZDT_OPTIONS`的条件下，
    发送`ZDT_SLOT_CW`或`ZDT_SLOT_CCW`。程序自动完成所选方向的粗定位、查询到位、
    最多10次同方向微调和三次高电平确认；成功返回
    `SLOT OK DIR=<CW或CCW> FINE=<次数> PB0=1`。
12. CW自动流程已完成一圈基础实测；有螺丝位置均能闭环到PB0=1，未安装螺丝的
    位置返回`GATE_NOT_FOUND`。CCW仍须单独测试一圈，记录反向间隙造成的微调次数。

建议记录表：

| 场景 | PB0第1次 | PB0第2次 | PB0第3次 | 结论 |
| --- | ---: | ---: | ---: | --- |
| 螺丝远离 |  |  |  | 背景电平待填 |
| 螺丝对准 |  |  |  | 到位电平待填 |
| 再次远离 |  |  |  | 是否恢复待填 |
| CW粗调后 |  |  |  | 应为0 |
| CW微调到位 |  |  |  | 应为1，记录微调次数 |
| CCW微调到位 |  |  |  | 应为1，记录微调次数 |

## 6. 预期现象与排错

- 正常：螺丝远离时稳定为一个电平，对准时稳定变为另一个电平，离开后恢复。
- 一直为1：PB0内部上拉在起作用，但OUT可能未接通、模块未供电/未共地、距离
  不合适，或者开集电极输出没有被触发。
- 一直为0：OUT可能持续导通、螺丝一直处于检测区、接线短路，或模块极性/阈值
  调节不合适。
- 0/1随机跳变：检查共地、线长、电机干扰和模块阈值；正式流程再增加连续采样
  消抖，第一轮先保留原始数据判断电气行为。

## 7. 与正式转盘流程的关系

光电门适合作为“机械槽位已对准”的确认信号，但不应单独替代ZDT状态。速度模式
依赖检测后再经UART/RTOS发送STOP，存在不确定延迟，因此本项目使用粗调和微调两级
位置命令。当前`ZDT_SLOT_CW`测试状态机已经实现以下闭环：

```text
ZDT命令已接收
-> ZDT_STATUS.REACHED=1
-> PB0连续多次等于实测到位电平
-> 才允许读卡或机械臂进入下一步
```

若电机到位但PB0未触发，应判为槽位校准或机械检测异常；若PB0触发但ZDT仍未
到位，也不能立即推进任务。
