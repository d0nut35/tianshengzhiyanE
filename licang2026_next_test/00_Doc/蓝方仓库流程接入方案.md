# 蓝方仓库流程接入方案

2026-10-08。状态：本方案已实施，正式及无线均接入蓝方阶梯/仓库差异，主机回归和五种Keil构建通过；尚未烧录/实机验证。按minimal-change-coding局部修改，修改前本地基线161f422，修改后另提交；197个既有换行差异及用户参数保留。

## 1. 已确认的场地含义

用户说明蓝方D1的用途对应红方D4空列，蓝D2/D3/D4的用途分别对应红D3/D2/D1。红方D1～D3有底部数字，蓝方D2～D4有底部数字；蓝方D1无底部数字，是积木放置列。小球不会有IC目标列4，只按底部实际识别的1～3映射放置。

| 项目 | 红方 | 蓝方 |
| --- | --- | --- |
| 空列/积木目标列 | D4 | D1 |
| 有数字的小球列 | D1、D2、D3 | D2、D3、D4 |
| 高层积木扫描 | D1→D2→D3 | D2→D3→D4 |
| 中/底层积木扫描 | D3→D2→D1 | D2→D3→D4 |
| 每层积木结束 | 返回D4放置/换层 | 返回D1放置/换层 |
| 积木后正式小球入口 | 返回D1 | 从D1到D2 |
| 小球结束 | 原D4收尾回家 | D4处理完，回D1再回家 |

这里的红蓝对应关系只描述列的用途。底盘仍接收原GO_DEPOT_1～4并回报原DEPOT_1～4_READY，分别到达本方D1～D4；Mission不把蓝方GO_DEPOT_1倒换成GO_DEPOT_4。坐标、点表、镜像方式、横移速度、首次找线入口和回家路线均不修改；其蓝方实机覆盖与停车可行性仍待验证。流程改变需要的横移通过原命令完成。

## 2. 蓝方积木抓放

1. 保留原仓库入口，确认本方D1实际到位。首层确认动作10；有效完成缓存可跳过重复10。
2. 在D1执行高层28并等匹配完成，然后去D2停车、稳定200ms才START新SID；D1为空列，不在这里开启积木数字识别。
3. D2无确认则去D3，再去D4；每个点均停车后建新会话，旧SID及运动帧不作为当前结果。
4. 有效数字1～3确认、结果ACK实际发送完成且事务邮箱消费后，执行当前源层夹取动作；等动作完成，保持夹取姿态返回D1；D1实际到位后按数字指定的目标层放置。
5. 放置实际完成后才记源层PLACED，然后在D1直接执行下一层识别姿态。中层与底层也从D2→D3→D4扫描，同层不重复识别姿态。
6. 某源层三点均NO_VALID：返回D1，不夹取、不放置，直接下一层；NO_VALID不能写成已证明物理空仓。设备/模型/帧故障仍停车。
7. 三层结束，D1执行10并等完成。新无线MOVE不放小球，由D1回家并等HOME_READY；正式从D1去D2并等实际到位，再进入小球流程。

| 源层 | 识别 | 夹取 |
| --- | ---: | ---: |
| 高 | 28 | 31 |
| 中 | 29 | 33 |
| 低 | 30 | 35 |

| 积木数字 | D1目标层 | 放置 |
| ---: | --- | ---: |
| 1 | 低 | 36 |
| 2 | 中 | 34 |
| 3 | 高 | 32 |

数字仍表示目标层，不是源层；不同源层数字互异。层间不插10，夹取到放置期间不插识别动作、转盘或独立撤离。红方现有积木流程保留。

## 3. 蓝方正式小球放置

- 积木结束10完成后到D2，初始化仓库工作参数时保留真实当前位置、真实球档案及实际转盘槽号；不得把D2到位写成D1。
- 复用原转盘准备：确认10，实际寻至物理12槽，PB0及故障保护保留。
- D2、D3、D4分别建立两次独立C100场景5会话；两次有效1～3相同且列号未重复，才把当前物理位置映射到该IC逻辑目标列。物理D2不固定为逻辑列2，物理D4也不固定为逻辑列4。
- 每列按真实当前位置选择本列CCW最近未放球，原manifest及异常球处理不变。目标层仍决定22→23/25/26→10；每个动作等实际完成回报，完整放置结束才记PLACED。
- 不在蓝D1识别C100数字或放小球；不新增目标列4任务，不修改共享IC/manifest协议支持范围。
- 蓝D4小球处理结束，确认10后用原GO_DEPOT_1返回D1；匹配请求编号及到位回报后进入原结束等待，再发送DEPOT_OK回家、等待HOME_READY。
- 返回D1使用独立收尾等待，不能误触发首次入口积木流程或重新初始化球档案。

## 5. 无线指令与兼容边界

不增加新命令名。ROUTE BLOCK MOVE在两方仍只搬积木、不放小球，结束本方D1回家；BLUE只选择蓝方走位/目标列，RED保持已验证红方行为。

```text

STATUS

```

BLUE后先等待READY ARM=10 MODEL=READY。烧录新无线固件，复位F7及底盘后测试；不要并开Nano预览抢设备。
