# HWT101 优化验证记录

本轮实现固定 `huart2` 的双文件驱动，正式目录只保留
`hwt101_adaption.c/.h`。测试、测量和本记录均不加入 Keil 正式目标。

## 构建与容量

2026-09-06，在修改前的当前工作树和修改后的工作树分别执行 Keil
`licang2026v1` 完整 Rebuild，均为 **0 Error(s), 0 Warning(s)**。
工具链保持 ArmClang 6.22、Cortex-M7、原工程优化选项；保留用户原有
CMSIS 6.1.0 配置修改。

| 项目 | 修改前 / B | 修改后 / B | 差值 / B |
|---|---:|---:|---:|
| 整机 Code | 59748 | 60044 | +296 |
| 整机 RO-data | 1552 | 1552 | 0 |
| 整机 RW-data | 24 | 24 | 0 |
| 整机 ZI-data | 118448 | 118464 | +16 |
| LR_IROM1（含链接对齐） | 61328 | 61624 | +296 |
| 64 KiB Flash 剩余 | 4208 | 3912 | -296 |
| HWT101 对象 Code 合计 | 988 | 1286 | +298 |
| HWT101 对象 ZI-data 合计 | 139 | 154 | +15 |

对象合计与整机差值的少量差异来自链接对齐。本版按用户确认的
“读取速度优先，允许少量额外代码和静态缓存”实现，**机器码并未缩小**。
旧基准文件未参与链接，其删除不计作 Flash 节省。固定 UART 指针原本
已被编译器消除，直接引用 `huart2` 用于落实固定硬件原则。

基线原文件、map、AXF 和对象文件保存在工程忽略目录
`tmp/hwt101_opt_before`；修改后完整构建日志位于
`tmp/hwt101_opt_after.log`。最终驱动源码、SHA256、构建日志和主机测量
输出另存于 `tmp/hwt101_opt_after`。

验收末尾，上层 App 和 BLE 出现本任务之外的并行改动，并重新生成了
共享 Keil 输出。本表记录 HWT101 单独修改时的构建日志和当时 map
结果；共享输出目录中的最新 map/AXF 可能已包含其他模块的变化，
不能直接用于重新计算本表的 HWT101 独立差值。

## 主机回归

运行 [run_hwt101_tests.ps1](run_hwt101_tests.ps1)，GCC `-O0` 和 `-O2`
下均通过以下检查：

- 保留七个适配 API、状态码、空指针检查、缺少 RX DMA、重复启动和
  PRIMASK 恢复；发送始终使用 `&huart2`、五字节帧和 100 ms 超时。
- 正常双帧、单类帧、同类多帧取最后一帧、坏校验、乱码、未知类型、
  截断帧、0～64 字节以及超长输入截断；失败不写输出，缺少 gyro
  保留调用方值。保持原先不跨 DMA 批次拼接残帧的行为。
- 100 次串行重复读取仅扫描一次；新批次替换缓存，无效批次不能
  回退旧有效值；软件标定立即生效，接收序号回绕使缓存正常失效。
- 解析中一次/两次 RX 切换、UART 错误、同批次另一任务读取、另一任务
  提前发布更新批次缓存；旧读取不能覆盖较新缓存或写出混合数据。
- RX/错误恢复挂接失败使数据失效，任务可通过 `start()` 重试。
- 30000 组随机报文与原扫描规则逐项对照；穷举全部 65536 个 int16
  输入，确认预计算比例与旧乘除表达式结果一致。
- 30000 组浮点标定输入与取余参考对照；非有限输入拒绝，极大有限
  输入可以收敛。多圈处理仅在标定路径运行，不引入固件取余库。

测试脚本只在 `.build` 中生成带两个解析观察点的源码副本，用于统计
扫描和模拟任务/ISR 插入；正式驱动没有测试宏、测试回调或 HAL 注入。

初始化只允许在停止接收时调用，活动接收期间返回 `HWT101_ERR`，防止
复位缓冲归属。`init/start` 由调用方串行执行；多个任务可以交错读取
和标定。缓存保存原始值；无新接收事件时重复读仍成功，不新增超时
失效策略。接收或错误事件使缓存失效。

## 主机耗时对照

运行 [run_hwt101_bench.ps1](run_hwt101_bench.ps1)。前后版本均使用
GCC `-O2`、相同模拟 HAL 和相同 22 字节双帧；预热后每项测量九轮，
每轮一百万次调用，记录中位数。此轮测量与 Keil 构建串行执行。

| 路径 | 修改前 / ns | 修改后 / ns | 观察 |
|---|---:|---:|---|
| 同批次重复读取 | 8.80 | 4.76 | 耗时下降约 45.9% |
| RX 入口 + 新批次首次读取 | 10.36 | 9.37 | 组合耗时下降约 9.6% |
| 完整模块 RX ISR 入口（HAL 模拟） | 1.86 | 1.84 | 接近，不据此宣称实机提速 |

性能程序直接编译原始正式源码，不使用回归测试的解析观察点。
原始输出保存在 `tmp/hwt101_opt_bench.txt`。重跑对照可通过
`-BaselineDir` 指定保存的旧驱动目录。

**以上是 Windows 主机测量，不是 F7 实机周期或实际 UART/DMA 耗时。**
本轮未烧录目标板，DWT 实机测试尚未执行。后续目标板对照需保持
相同系统时钟、编译选项、缓存配置与传感器输出，分别用 DWT CYCCNT
记录首次读取、缓存命中和包含 HAL 重启的完整 RX ISR；计时结果在
任务中输出，ISR 内不打印。不使用旧基准中仅记录长度/切换标志的
模拟片段作为真实 ISR 耗时。
